Pitch deck
01
The problem

“Was this written by a machine?” has no honest one-detector answer.

  • Single detectors overfit one model family — a 2023-ChatGPT detector misses two-thirds of modern-LLM text, and vice-versa.
  • Most tools emit a confident number with no calibration — the probability isn't a probability, and there's no interval around it.
  • Verdicts arrive as black boxes: no spans, no per-feature contribution, nothing an analyst can defend.
  • Adversarial edits (paraphrase, verbosity-low, synonym swap) quietly collapse accuracy — and you find out in production.

Detection that can't show its work, quantify its uncertainty, or survive a new model release isn't verdict-grade.

02
What CAIRN is

A multi-detector fusion pipeline that produces a defensible verdict.

🧩

17 detectors, 4 phases

Pattern, statistical, and LLM-backed signals fused into one score — not a single model's opinion.

📊

Calibrated & conformal

EBM fusion + isotonic calibration + split-conformal interval. The probability means what it says.

🔍

Evidence, not vibes

Character-level spans, per-feature contributions, and a transparent decision band.

  • Verdict bands: RED AMBER GREEN plus UNCERTAIN abstention when the conformal set is too wide.
  • One pipeline behind three shells — the engine is identical whether you call the GUI, the REST API, or the desktop app.
03
Three runtimes, one engine

Same pipeline. Pick the shell that fits the deployment.

cairn gui

Stdlib HTTP server + single-file SPA. Tabs for analyze, batch, history, monitoring, evaluation, settings. Zero heavy deps.

cairn serve

FastAPI REST service for integrations and back-office automation. Same determinations over HTTP/JSON.

Desktop shell

Tauri 2 wraps a cairn.sidecar subprocess over stdio JSON-RPC. Ships as .msi / .dmg / .AppImage.

Loopback-first: the GUI binds 127.0.0.1 by default and the desktop shell never opens a port. Text stays on the machine unless you opt in.

13
Privacy by default

The text doesn't leave unless you say so.

  • Loopback-first. GUI binds 127.0.0.1; the desktop shell opens no port at all.
  • Hash-only history. gui.history.retain_text defaults to false — submissions are stored as hashes.
  • Minimal egress. contrastive_gen sends only the task description to a provider, never the submission text — and there's a test that keeps it that way.
  • Config redaction. _redact scrubs secrets / API keys / tokens before any config is surfaced.
  • Offline by default. Tier-3 LLM-backed detectors are opt-in and require explicit API credentials.
14
What we don't pretend

Read this before you deploy.

  • OOD is hard by design. master_minus_arxiv is ~0.94 in-domain but ~0.68 on RAID and ~0.57 on MAGE — genres it never trained on. Recalibrate against your real input distribution.
  • Conformal coverage assumes in-distribution data. On OOD the set widens but the guarantee no longer holds.
  • Some detectors carry near-zero signal post-calibration — the EBM weights them toward zero; they're flagged removal candidates, not hidden.
  • No auth or rate limiting on the HTTP / FastAPI transports yet — front with a reverse proxy if you expose beyond a single machine.
  • Heuristic detectors are genre-sensitive — disciplined human prose (SOPs, clinical protocols, legal briefs) can trip them. The trained EBM accounts for this.
15
Where it's heading

On the roadmap

Profile auto-routing

Today the pipeline routes prompt/prose/mixed but profile choice is deployment-time. Auto-pick by input shape is next.

Persistent drift window

Baselines rebuild from history on demand; the in-flight observation window is lost on sidecar restart — make it durable.

Non-loopback hardening

Auth, rate limiting, and a vetted exposure story for cairn serve beyond a single machine.

Adversarial coverage

Verbosity-low and RAID transforms are the live attack surface — keep widening the calibration corpus against them.

New-model refresh

The matched per-provider corpus is reusable: re-run it on each frontier release to track detection difficulty.

Detector pruning

Retire the near-zero-signal detectors once the EBM confirms they add no discriminative power.
